# Foxford Chat Autoscroll

Небольшое расширение для Chromium-браузеров, которое добавляет в чат урока
Фоксфорда четвёртую кнопку — переключатель автоматической прокрутки к новым
сообщениям.

## Возможности

- работает на страницах `https://foxford.ru/groups/*`;
- добавляет кнопку рядом с ограничением отправки, скрытием чата и настройками;
- включается и выключается одним нажатием;
- сохраняет выбранное состояние для следующих уроков и групп;
- не читает и не отправляет содержимое сообщений;
- не обращается к сторонним серверам.

## Установка в Яндекс Браузер

1. Скачайте этот репозиторий и распакуйте архив.
2. Откройте `browser://extensions/`.
3. Включите режим разработчика.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку, в которой находится `manifest.json`.
6. Обновите открытую страницу урока Фоксфорда.

## Установка в Chrome или Edge

Откройте `chrome://extensions/` или `edge://extensions/`, включите режим
разработчика, выберите загрузку распакованного расширения и укажите эту папку.

## Использование

На странице урока откройте чат. Рядом со штатными кнопками появится значок со
стрелкой вниз. Фиолетовый фон и зелёная точка означают, что автопрокрутка
включена. Повторное нажатие выключает её.

## Приватность

Расширение хранит только один локальный параметр: включена ли автопрокрутка.
Данные чата не сохраняются и никуда не передаются.
